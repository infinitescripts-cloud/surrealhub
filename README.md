# 🎭 Surreal Hub

A lightweight, **Camp-only** Total Roblox Drama script built on the **Luna Interface Suite**.

Surreal Hub was built with one goal: give Camp players exactly what they need without the lag, bloat, or crashes you find in most TRD scripts.

---

## ✨ Features

### 🗳️ Voting
- Notify Votes
- Print Votes to console
- Expose Votes to public chat
- View Jury Votes
- View Exile Votes (Camp)

### 🏆 Statue
- Find Statue (60% spawn)
- Get Statue on Spawn
- Detect Who Has Statue

### 📊 Round Info
- Auto Detect Round (Purge, Double, Sike, Exile, Vote Reveal)
- Detect Teamers (friend-pair scanner)

### 🎮 Challenges
- Win Obby + Auto Win Obby
- Answer Math Mania (auto-solver with adjustable setback)
- Win Blockpush
- Dodgeball Invincibility
- Paintball Invincibility
- Remove Spleef Studs
- Finish Pancake
- Get Dodgeballs
- Kill Everyone in Swordfight
- Cliff Diving ESP
- Auto Collect Coins & Gems

### 🎨 Visuals
- Starborn Typeface
- Minecraft Typeface
- Matcha Mint Typeface
- OG Roblox Typeface
- Custom Character Name
- Rainbow Name + adjustable speed
- Name Color picker

### 👁️ Global Nameplates
Give every player in the lobby a custom overhead name in the **Luckiest Guy** font with a smooth silver gradient.

### 🛠️ Utilities
- Water Walk (walk on the lake without drowning)
- Barrier Cleanup (removes Glass, ChallengeGlass, AwardCeremony, Drop-Off)
- FE Genesis Sniper
- Infinite Yield
- Energize R6

### 🚀 Teleports
- Spectator Island
- Main Island
- Exile Island
- Voting Area
- Boat
- Bathroom

---

## 🛡️ Stability

Every single callback is wrapped in a safety handler. If the game updates and breaks a feature, you'll see a single clean warning in the console — **the rest of the UI keeps working**. No more red error spam. No more crashes. No more rebooting your executor mid-match.
